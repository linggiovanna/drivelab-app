# DriveLab · 车载硬件知识卡（iPhone 优先）

## 当前版本
- 预置约 80 张知识卡，来源于《记录仪核心知识（学习版）》、欧洲车牌检测阶段性分析报告，以及此前项目讨论中的 DR2864、连接体验、神眸 DC1、4G 埋点、产品走查等内容。
- 支持每日学习、卡片翻面、间隔复习、分类检索、手动新增、JSON 导入和学习数据导出。
- 数据默认保存在当前浏览器本地，不需要账号，不会自动上传。
- 当前版本不接外部 AI API。新文档可先交给 ChatGPT 按提示词生成 JSON，再导入 App。

## 在电脑上预览
解压后用浏览器打开 `index.html` 即可预览。建议使用 Safari 或 Chrome。

## 在 iPhone 上添加到主屏幕
PWA 安装和离线缓存需要 HTTPS 地址。将整个文件夹部署到你自己可访问的 HTTPS 静态站点后：
1. 用 iPhone 的 Safari 打开该 HTTPS 地址。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。
4. 添加后从主屏幕图标打开，即以独立窗口运行。
5. 首次打开完成缓存后，可在无网络时使用已缓存的卡片。

**隐私提醒：** 由于知识卡包含你工作项目中的技术讨论和测试数据，不建议把文件夹公开部署到任何人都能访问的网站。应使用你自己的私有站点或带访问控制的托管方式。当前包没有登录和云端同步，学习记录只在当前浏览器中。

## 如何持续增加知识
1. 在 App「我的」中点击“复制 AI 制卡提示词”。
2. 在 ChatGPT 中上传新文档，并附上提示词。
3. 要求只输出 `{"cards":[...]}` 格式 JSON。
4. 下载 JSON 后，在 App「我的」中选择“导入卡片 JSON”。
5. 导入后会按卡片 ID 或问题文本合并，尽量避免重复。

## 备份
在「我的」中点击“导出学习备份”，会导出全部卡片与复习记录。更换浏览器或清理网站数据前，请先导出备份。

- 这不是 App Store 原生 iOS 应用，而是可添加到 iPhone 主屏幕的 PWA。
- 资料中的通用参数、项目测试数据和具体型号规格有不同适用范围，卡片已尽量保留来源和核验状态。涉及最终产品结论时，仍需回到冻结规格书、研发确认和实测结果。
